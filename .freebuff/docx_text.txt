


Mafia Game: Task Split (Abaid and Jawad)

Ticket details (description and &quot;Done when&quot;) are in mafia-tickets.md. This file only says who does what and in what order.


Roles

Abaid: Screens, UI components, navigation, client-side logic.

Jawad: Supabase schema, RLS, Edge Functions, accounts and settings, builds and releases, and any ticket that mixes frontend and backend.

Asad: reviews every pull request, creates the third-party accounts (LiveKit, Firebase, Google Cloud, Google Play Console), and joins the playtests.


Working rules for the split

Jawad. Most of Abaid's screens need a backend ticket from Jawad first (the &quot;Needs&quot; column). Jawad should finish each phase's backend tickets before Abaid reaches the matching screens.

Abaid never waits idle. While a backend ticket is pending, build the screen against mock data (a local fake object), then swap in the real Supabase calls when Jawad's ticket is merged.

Split tickets (026, 034, 035, 083) have a backend half for Jawad and a screen half for Abaid. Jawad merges the backend half first.

Extra review on the tickets that protect hidden information: 040, 045, 060, 071, 074.

Branch name: feature/MAF-xxx-short-name. One ticket, one PR into dev.
